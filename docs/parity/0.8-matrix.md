# Legacy parity matrix — Okkhor 0.8

Status: **0.8 release candidate**. This matrix is the single source of truth for
legacy capability coverage. It is **not a full-parity claim**: 0.8 inspects the
owner-provided Kontho install and imports none of it automatically.

Owner: Atik. Reviewed: 2026-11-24. Related documents:
[docs/compatibility.md](../compatibility.md),
[ADR 0005](../adr/0005-legacy-reuse-via-compatibility-layer.md),
[ADR 0013](../adr/0013-encodings-and-fonts.md),
[ADR 0014](../adr/0014-input-modes-hotkeys-fonts.md),
[ADR 0020](../adr/0020-suggestion-stability-and-raw-fallback.md).

Status vocabulary:

- **supported** — Okkhor provides the capability today, or obtains the asset
  through its own installer without reading legacy data.
- **partial** — the capability exists with a documented gap or a different
  mechanism; the gap is named in the row.
- **unsupported** — not implemented or not imported; the reason and the next
  owner action are named. Nothing is silently dropped.

Evidence comes from `scripts/import-legacy.ps1` run read-only against the
owner install. The report records counts, sizes, SHA256s, and container magic;
it never deserializes pickle, never parses `WTR1`/`STRI` payloads, and never
prints custom-word text. Reproduce with:

```powershell
.\scripts\import-legacy.ps1 -LegacyHome "<install>" -DataHome "<temp>" -Apply
```

## What this means for 0.8

- 0.8 is a stability and evidence release, not a migration release. The import
  report proves what exists, what the containers are, and what was skipped.
- No proprietary binary, layout, dictionary, setting, or history file enters
  the repository. The report is written only under the Okkhor data home.
- `settings.pkl`, `*.nmsLayout`, `*.nmsEnco`, and `SentenceHistory.pkl` remain
  unread pickle. `WTR1` and `STRI` remain unparsed containers.
- The compatibility exit criteria in
  [docs/compatibility.md](../compatibility.md) are still open: top-5 corpus
  parity, clean layout import, custom-word/shortcut migration, and no required
  legacy DLL at 1.0.
