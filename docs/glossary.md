# Glossary

| Term | Meaning |
| --- | --- |
| **Akkhor** | The product: a Windows-first Bengali/English input engine. |
| **Bornomala** | The transliteration and language engine. |
| **Smriti** | The local personalization/learning engine. |
| **Legacy application** | The previous product, used only as a behavioral oracle during migration. |
| **Legacy build** | The owner-provided installation kept side-by-side during migration. |
| **Banglish** | Romanized Bengali used for phonetic input (`bhalo`, `kemon`). |
| **Avro** | A popular Bengali phonetic keyboard layout. |
| **National / Jatiya** | A Bengali keyboard layout. |
| **Probhat** | A Bengali keyboard layout. |
| **Bijoy** | A Bengali keyboard layout and encoding family. |
| **Khipro** | A Bengali phonetic layout. |
| **NFC** | Unicode Normalization Form C. |
| **Grapheme cluster** | A user-perceived character; in Bengali, may include a base letter and marks. |
| **Virama / hasant** | A combining mark that suppresses the inherent vowel and can form conjuncts. |
| **ZWJ / ZWNJ** | Zero-width joiner / non-joiner; affect Bengali conjunct rendering. |
| **Bigram** | Two adjacent words used as a context signal. |
| **Base index** | Immutable bundled dictionary/layout data. |
| **Delta index** | Mutable user-specific learning data. |
| **p99** | The 99th percentile latency; the worst 1% of samples. |
| **UIPI** | User Interface Privilege Isolation; blocks lower-integrity input into elevated windows. |
| **DPAPI** | Windows Data Protection API for encrypting local data. |
| **WH_KEYBOARD_LL** | Windows low-level keyboard hook. |
| **SendInput** | Windows API for synthesizing keyboard/mouse input. |
| **SBOM** | Software bill of materials. |
