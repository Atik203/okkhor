# 0.5 alpha — interactive QA checklist

Release rule: **no tag and no public artifact until every `P0` row passes.**
`P1` rows may be deferred only with a written follow-up issue linked here.
Automated rows are evidence from CI or `scripts/qa-alpha.ps1`; interactive rows
require a human at a real keyboard on a real Windows desktop.

Status values: `not run`, `pass`, `fail`, `blocked (owner)`, `automated`.
Record the date, build commit, OS build, and tester for every run.
