# Okkhor 0.8 suggestion stability checklist

Owner: Atik. These rows cover the Kontho/Bongo-inspired stability work.
Automated gates are in `scripts/qa-0.7.ps1` plus the commands below; the
real-key rows still need the owner because the hook ignores injected keys.

## Automated gates

| Row | Command | Pass |
| --- | --- | --- |
| Format | `cargo fmt --all -- --check` | [ ] |
| Lint | `cargo clippy --workspace --all-targets -- -D warnings` | [ ] |
| Rust suites | `cargo test --workspace --locked` | [ ] |
| Popup render | `cargo test -p okkhor-win manual_smoke_paints_five_rows_at_a_fixed_anchor -- --ignored --nocapture` | [ ] |
| Golden ranking | `cargo test -p okkhor-engine --test suggestions` | [ ] |

The popup render row opens a real window at screen (400, 200) for eight
seconds. It is the visual check for the card, selected row, and double
buffering; it does not depend on a live caret.

## Real-key rows (owner)

| ID | App | Step | Expected |
| --- | --- | --- | --- |
| P-01 | Notepad | Type `bhalo` slowly | List appears once near the caret; no flicker |
| P-02 | Notepad | Type a 10-character word at speed | List updates calmly; no one-character jump |
| P-03 | Chrome | Type a word, Space, immediately type the next word | Popup appears for the second word |
| P-04 | Chrome | Backspace to a previous prefix, retype the last letter | Rows and order are identical |
| P-05 | Chrome | Move the caret with arrows while the list is visible | List follows; no focus theft |
| P-06 | Notepad | Type `also` | Bangla rows first; `also` is selectable on the last row |
| P-07 | Notepad | Type `also`, press Space | Top Bangla row commits; no Latin pair is learned |
| P-08 | Notepad | Type `also`, press End/Down then Space | The raw `also` row can be committed |
| P-09 | Notepad | Type a word, press Esc | List hides; roman text stays |
| P-10 | Any | Pause UI Automation by opening a heavy app, type | A failed probe never leaves the list hidden |
