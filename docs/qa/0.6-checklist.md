### English
- [ ] `hel` shows hello/help; Tab accepts the top row
- [ ] Space/Enter/punctuation never replace the token
- [ ] A fully typed word hides the list so Tab moves focus normally
- [ ] Esc dismisses; a click accepts the clicked row
- [ ] Password fields show no popup and Tab is not consumed
- [ ] Settings -> English suggestions off hides the feature

### State and shell
- [ ] F9 changes the quick-bar chip within ~100 ms
- [ ] Tray language toggle and pause update the chip
- [ ] Bar encoding cycle updates the chip
- [ ] Bar position/width persist across restart
- [ ] Settings at 960/1280/1600 px, light and dark: no overflow, all controls work
- [ ] About shows 0.6.0; `bin\okkhor-engine.exe --version` prints `okkhor 0.6.0`

### Reliability
- [ ] Fresh extraction: Okkhor.exe starts the engine; Settings connects; bar visible
- [ ] Restart: settings, learned words, and bar position persist
- [ ] Rename `bin\okkhor-engine.exe` or corrupt the index -> typing still works on the rule path, no panic
- [ ] Quit from tray/bar stops both processes
- [ ] No duplicate `okkhor-engine.exe` after rapid launch/quit
