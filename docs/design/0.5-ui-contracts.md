# 0.5 UI contracts (binding)

Status: binding for the 0.5 milestone. Implementation must match this document;
deviations need a recorded ruling from the lead before merge.

Related: ADR 0004 (UI shell), ADR 0012 (UI process, IPC, settings ownership,
encrypted store), `docs/security-privacy.md`, `docs/performance.md`.

## 1. Scope

0.5 delivers a settings and utility UI in a separate process:

- status overview (daemon state, pause state, language/layout, version);
- settings (language, layout, popup, theme, accent, font, hotkey, autostart,
  learning, AI/speech opt-in placeholders);
- on-screen keyboard (click-to-insert, groups, recents, favorites);
- word manager (list, search, add, remove, import/export);
- accessibility, keyboard navigation, 100–200% DPI, no focus theft.

Not in 0.5: AI/speech behavior (0.6), installer (1.0), popup redesign, cloud.

## 2. Settings schema v1

Persisted by the daemon at `%LOCALAPPDATA%\Okkhor\settings.json` as plaintext
JSON. The daemon is the single writer. Unknown fields are ignored on read and
dropped on write.

```json
{
  "schema": 1,
  "language": "bn",
  "layout": "avro",
  "input_mode": "bangla",
  "output_encoding": "unicode",
  "theme": "system",
  "accent": "teal",
  "font_scale": 1.0,
  "font_family": null,
  "font_unicode": "kalpurush",
  "font_bijoy": "kalpurush-ansi",
  "popup_enabled": true,
  "popup_max_items": 5,
  "toggle_hotkey": "F9",
  "pause_hotkey": "Ctrl+Alt+Shift+P",
  "show_toggle_toast": true,
  "quickbar_visible": true,
  "quickbar_collapsed": false,
  "quickbar_x": null,
  "quickbar_y": null,
  "quickbar_opacity": 0.9,
  "autostart": false,
  "learning_enabled": true,
  "word_manager_page_size": 50,
  "ai_enabled": false,
  "speech_enabled": false
}
```

| Field | Type | Default | Bounds / rules |
| --- | --- | --- | --- |
| `schema` | u32 | `1` | must equal 1; other values → `UnsupportedSchema` |
| `language` | `"bn"` \| `"en"` | `"bn"` | rejects other values |
| `layout` | string | `"avro"` | `okkhor_lang::LayoutId::from_code`; unknown → `InvalidLayout` |
| `theme` | `"system"` \| `"light"` \| `"dark"` | `"system"` | |
| `input_mode` | `"bangla"` \| `"english"` | `"bangla"` | last mode persists |
| `output_encoding` | `"unicode"` \| `"bijoy"` | `"unicode"` | per ADR 0013 |
| `accent` | `"teal"` \| `"indigo"` \| `"amber"` \| `"rose"` | `"teal"` | |
| `font_scale` | f32 | `1.0` | clamp `0.8..=1.6`, reject NaN |
| `font_family` | string? | `null` | trim, max 64 chars, ASCII printable only |
| `font_unicode` | `"kalpurush"` \| `"siyam-rupali"` \| `"noto-sans-bengali"` | `"kalpurush"` | unknown → default |
| `font_bijoy` | `"kalpurush-ansi"` \| `"sutonnymj"` | `"kalpurush-ansi"` | `sutonnymj` only if detected |
| `popup_enabled` | bool | `true` | |
| `popup_max_items` | u8 | `5` | clamp `1..=9` |
| `toggle_hotkey` | string | `"F9"` | single key preferred; invalid → `InvalidHotkey` |
| `pause_hotkey` | string | `"Ctrl+Alt+Shift+P"` | parse via `okkhor_win::Hotkey`; invalid → `InvalidHotkey` |
| `show_toggle_toast` | bool | `true` | |
| `quickbar_visible` | bool | `true` | |
| `quickbar_collapsed` | bool | `false` | |
| `quickbar_x` | i32? | `null` | auto top-right when null |
| `quickbar_y` | i32? | `null` | auto top-right when null |
| `quickbar_opacity` | f32 | `0.9` | clamp `0.5..=1.0` |
| `autostart` | bool | `false` | applied through existing autostart module |
| `learning_enabled` | bool | `true` | false disables learned ranking and new learning |
| `word_manager_page_size` | u16 | `50` | clamp `10..=200` |
| `ai_enabled` | bool | `false` | 0.6 wires behavior; 0.5 persists only |
| `speech_enabled` | bool | `false` | 0.6 wires behavior; 0.5 persists only |

`SettingsPatch` carries only set fields (all `Option<T>`); the daemon merges,
validates the merged value, then writes atomically (temp file + rename).

## 3. User words

Sensitive text; stored only in the encrypted repository at
`%LOCALAPPDATA%\Okkhor\data\words.bin` via DPAPI (current-user scope).

```json
{
  "schema": 1,
  "words": [
    {
      "id": 7,
      "roman": "amar",
      "output": "আমার",
      "language": "bn",
      "source": "user",
      "added_at_ms": 1763900000000
    }
  ]
}
```

- `id`: u64, monotonically increasing, assigned by the daemon.
- `roman`: 1–64 chars, no control characters.
- `output`: 1–128 Unicode scalar values, no control characters except ZWJ/ZWNJ.
- `language`: `"bn"` or `"en"`.
- `source`: `"user"`, `"import"`, or `"learned"`.
- Total words cap: 20,000. Import cap per request: 5,000 rows; over cap →
  `TooManyWords`.
- Duplicate `(language, roman, output)` is rejected with `DuplicateWord`.
- Import format: CSV with header `roman,output,language` or JSON matching the
  schema above without `id`/`added_at_ms`.

## 4. IPC protocol v1

Pipe name: `\\.\pipe\okkhor-ipc-v1`. One instance per concurrent client, max 4.

Frame: `u32` little-endian length, then UTF-8 JSON, max 1 MiB.

Every connection sends exactly one `hello` as its first request:

```json
{"hello":{"protocol":1,"token":"<64 hex chars>"}}
```

Response: `{"hello_ok":{"protocol":1,"daemon_version":"1.0.0","pid":1234}}`.

Requests (tagged enum, one per frame):

| Method | Params | Result |
| --- | --- | --- |
| `status` | `{}` | `Status` |
| `settings.get` | `{}` | `Settings` |
| `settings.update` | `SettingsPatch` | `Settings` |
| `layouts.list` | `{}` | `[{"code":"avro","name":"Avro"}]` |
| `words.list` | `{"query":null,"offset":0,"limit":50}` | `{"total":N,"words":[Word]}` |
| `words.add` | `{"roman":"...","output":"...","language":"bn"}` | `Word` |
| `words.remove` | `{"id":7}` | `{"removed":true}` |
| `words.import` | `{"format":"csv"\|"json","data":"..."}` | `{"imported":N,"skipped":N}` |
| `words.export` | `{"format":"csv"\|"json"}` | `{"format":"csv","data":"..."}` |
| `text.insert` | `{"text":"..."}` | `{"inserted":true}` |
| `capture.set` | `{"paused":true}` | `Status` |
| `ai.complete` | 0.6 only | typed `Unsupported` in 0.5 |

Limits: `text.insert` ≤ 512 UTF-16 code units; `words.list` limit ≤ 200;
export ≤ 1 MiB; import payload ≤ 1 MiB. Server read timeout 10 s, per-request
timeout 5 s.

Errors: `{"error":{"code":"InvalidLayout","message":"..."}}` with codes from
the list in `crates/okkhor-ipc/src/error.rs`. Messages never include user text.

`Status`:

```json
{
  "daemon_version": "1.0.0",
  "paused": false,
  "language": "bn",
  "layout": "avro",
  "popup_visible": false,
  "words_total": 42,
  "learning_enabled": true,
  "autostart": false
}
```

## 5. UI requirements

Routes: `/` status, `/settings`, `/keyboard`, `/words`, `/about`.

Behavior:

- First run requires no configuration: Bangla mode, Unicode output, Kalpurush
  font, F9 toggle, fonts installed per-user in the background. No font picker
  and no wizard.
- On load: connect; if the pipe is unavailable, show a persistent
  "Okkhor daemon is not running" banner, render last-known settings read-only
  from the file, and disable destructive actions.
- Tray left-click toggles Bangla/English; the tray menu exposes
  Bangla/English, Output Unicode/Bijoy, Pause, Settings, Exit. A toggle shows a
  non-activating toast and updates the tooltip.
- Never write `settings.json` directly. Never display raw keystrokes.
- Focus: settings window may activate; the suggestion popup must not. The UI
  never creates always-on-top windows.
- Theme follows system by default; accent and font scale apply live.
- Keyboard: full tab order, visible focus ring, Escape closes dialogs, Enter
  submits, `aria-live` announcements for save/error toasts.
- Screen readers: every control has an accessible name; icon-only buttons have
  `aria-label`; lists expose row counts.
- DPI: usable at 100/150/200%; no clipped controls; the window is resizable and
  remembers size in `localStorage` only (non-sensitive).
- On-screen keyboard: layouts read from the daemon; click inserts through
  `text.insert`; groups and favorites persist in settings/word store; recents
  are session-only (no keystroke persistence).
- Word manager: paginated list, search, add form with validation mirroring the
  contract, remove with confirmation, CSV/JSON import preview and export.

## 6. Acceptance gates

- `cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
  `cargo test --workspace` pass on the root workspace.
- `npm ci && npm run build && npm test` pass in `apps/okkhor-ui`.
- IPC tests cover: framing bounds, oversized frame rejection, bad token, wrong
  protocol, timeout, unknown method, settings validation, word validation,
  duplicate rejection, import cap, export round-trip.
- Settings tests cover the new fields: `input_mode`, `output_encoding`,
  `toggle_hotkey`, `pause_hotkey`, `font_unicode`, `font_bijoy`,
  `show_toggle_toast`, including hotkey conflict fallback and invalid values.
- Encoding tests cover Unicode → Bijoy golden strings, pre-base reordering,
  digits/taka/punctuation, inverse approximation, and the 4096-char bound.
- Font tests cover idempotent per-user install/uninstall (dry-run), detection
  of SutonnyMJ, and the Noto fallback path.
- Storage tests cover: DPAPI round-trip (Windows), tamper rejection, atomic
  replace, schema rejection.
- Manual QA checklist added to `docs/qa/` with focus-theft, DPI, keyboard-only,
  screen-reader, crash-isolation, and cold-start rows. Execution on a real
  desktop remains owner-gated; rows are marked `not run` honestly.
- Docs updated: README, architecture crate table, roadmap status, settings
  reference, security privacy notes.

## 7. Performance

- UI cold start target < 1 s on the reference machine; measured and recorded,
  not asserted.
- IPC status round-trip < 5 ms p99 locally; settings save < 20 ms p99.
- No UI code is linked into the hook path. The daemon's hot-path budgets are
  unchanged.
