## What shipped

### Fixed

- **User mapping priority.** A custom pair such as `ammar -> আমার` now uses a
  base score (1.98) above curated (1.30) and dictionary rows. Before this,
  adding a word did not guarantee it appeared first. A regression test pins the
  exact case.

## Note on global learning

Custom words are **local-only** today. Copying them into a global frequency
model would send user text off-device without consent, which violates the
project privacy contract. A global contribution has to be explicit opt-in,
aggregated and differentially private. That design is part of the 0.10.0
learning plan, not this patch.
