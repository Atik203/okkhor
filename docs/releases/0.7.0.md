# Okkhor 0.7.0 beta

- Date: 2026-11-24
- Channel: prerelease (portable, unsigned)
- Artifact: `Okkhor-0.7.0-win64-portable.zip`
- SHA256: recorded after the final build in `SHA256SUMS.txt` and the GitHub release

## What shipped

### Typing and caret

- Caret and password UI Automation now run on a dedicated latest-wins thread.
  Typing never waits on UIA; a visible popup follows a newer caret without
  repainting, and a hung UIA call cannot block daemon shutdown.
- The English popup waits for a sample newer than the latest request before
  trusting the password flag, so a previous field cannot leak a completion into
  a password box.

### Local model

- `okkhor-features`: shipped v1 feature vector; the frozen replay
  byte-compatibility hash is unchanged.
- `okkhor-model`: checksum-verified embedded logistic reranker, structural work
  bound (64 x 16), no clock read, exact baseline fallback.
- `--ranker baseline` remains the default. `--ranker hybrid` is opt-in.
- Synthetic A/B is an exact identity (no learning evidence); no quality claim.

### AI rewrite

- Opt-in Settings card and explicit **Try a rewrite** action.
- Isolated `okkhor-worker.exe`, private pipe/token, lazy spawn, job
  poll/cancel/status, bounded queue/map.
- OpenAI first; `gpt-6-luna` default, `gpt-6.1-terra` quality option. The key is
  read from `OKKHOR_OPENAI_API_KEY` (or a local `.env`) and never persisted.
- Prompts/responses are memory-only; results are never inserted automatically.
- Live smoke test: `gpt-6-luna` returned a rewrite in 1.25 s with 13 input /
  7 output tokens.

### Data and QA

- Dataset manifest v1 with fail-closed verifier; deterministic trainer.
- 10,000-event session stress test.
- `scripts/qa-0.7.ps1`, `docs/qa/0.7-matrix.md`, and
  `docs/qa/0.7-checklist.md`.

## Known limits

- Unsigned; SmartScreen warns. No installer, updater, or signing until 1.0.
- Hybrid reranker is synthetic-only and default-off.
- AI requires a key; it is not bundled.
- IME/RDP/elevated/DPI rows are manual and owner-gated.
- Real-key caret/English/password QA is owner-gated; the hook ignores injected
  keys.

## Upgrade notes

- 0.6 profiles keep working; the five-row legacy default was already migrated
  in 0.6.
- New files: `bin\okkhor-worker.exe`.
- AI is off by default; no settings migration is required.
