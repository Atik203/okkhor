# Okkhor 0.8.0

Portable Windows 11 x64. **Unsigned unless the release build is signed with a
trusted Authenticode certificate.** No installer or auto-update yet.

## Highlights

### Input feel

- The suggestion card is updated in place, moves only when the caret placement
  actually changed, keeps a stable width, and paints through a memory DC.
- Fast typing coalesces visible paints to 30 ms. The engine and commit state
  still update on every key, so Space, digits, and clicks always commit the
  current row.
- A completed caret sample is published even when a newer one is queued; the
  daemon falls back to the last anchor and re-shows the popup when a late
  sample arrives.
- Recency is frozen for one composition, a 16-entry prefix cache returns the
  same rows after backspace/retype, and an arrow-key selection stays on its row
  across later keystrokes.

### Unknown Banglish

- Bangla mode keeps the typed Latin token as the last row. If no
  dictionary-backed Bangla candidate exists, a few English prefix completions
  are added below the Bangla rows.
- Latin fallback commits are not learned as Bangla transliteration pairs.

### Standard layouts and naming

- The internal `banglish` layout code is now the canonical `phonetic`. Old
  `settings.json` values are migrated on load; the UI shows `Phonetic`.
- `Bangla (National)` (Jatiya) is available with 77 mappings stored in
  `national-v1.json`. Okkhor implements the public standard independently; it
  does not depend on any other keyboard product at runtime.

### Legacy migration

- `scripts/import-legacy.ps1` is a read-only inspection and migration report
  for the owner-provided Kontho install. It records counts and SHA256s, reports
  unsupported formats, and never deserializes `settings.pkl` or other pickle
  data.
- The 0.8 parity matrix records what is supported, partial, or unsupported.
  `WTR1`/`STRI` dictionaries and pickle-based layouts/encodings are recognized
  but not imported in this release.

### Windows release

- The portable build uses the MSVC toolchain (`x86_64-pc-windows-msvc`) and
  the 2026 stable Rust toolchain. Rust's current edition is 2024; there is no
  edition 2026.
- `scripts/build-beta.ps1` accepts a PFX or certificate thumbprint, signs the
  three executables with `signtool`, timestamps them, and verifies them.
- Without a trusted certificate the build is unsigned and SmartScreen will
  warn. A self-signed certificate only works on machines that trust it and is
  not a release fix.

## Verification

- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace --locked`
- daemon self-check
- suggestion-index checksum
- UI build and tests
- legacy import report against the owner install
- portable MSVC artifact built; SHA256 recorded in `SHA256SUMS.txt`

## Known limits

- No installer, updater, or code signing certificate is included.
- Full `WTR1`/`STRI` dictionary import and pickle-based layout import are not
  implemented; the matrix reports them instead of guessing.
- No new model was trained for 0.8. The 0.7 synthetic Tier 1 reranker remains
  default-off.
- Inline preedit, punctuation commit, emoji, Tab cycling, and accepted/corrected
  suggestion learning are not part of this release.
- Real-key QA remains the owner's pass: `docs/qa/0.8-checklist.md`.
