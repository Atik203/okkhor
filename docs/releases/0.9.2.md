0.9.2 is a second bugfix patch from daily use in Notepad.

## What shipped

### Fixed

- **Bangla Tab no longer leaves one letter behind.** Tab was not in the
  swallowed composition set, so Notepad inserted a tab before the commit
  erased the roman buffer. Tab is now swallowed like Space and commits the
  highlighted candidate.
- **Stuck key repeats.** The hook now records each swallowed key-down in its
  own flag instead of one "last key" slot. Overlapping Down/Tab presses can no
  longer leave a key looking held.
- **Double Tab.** A swallowed Tab is re-emitted only when the hook actually
  took it, so Notepad does not receive both a tab and a re-emitted Tab.

### Added

- **English live preview.** Up/Down replace the typed word in the document in
  real time. Tab still accepts and Space finalizes, so the preview is
  optional. The original token is replaced safely on each step.

  is the 0.10.0 feature, not part of this patch.
- Unsigned build: SmartScreen/Defender still warn until a trusted certificate
  is configured.
