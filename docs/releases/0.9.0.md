# Okkhor 0.9.0

Date: 2026-11-24
Channel: beta (portable, unsigned unless the owner signs the build)
Artifact: `Okkhor-0.9.0-win64-portable.zip`
SHA256: filled from `SHA256SUMS.txt` after the tagged build.

0.9.0 makes every advertised layout real. It is a feature release on top of
0.8.1 and keeps the 0.8 suggestion-stability behavior.

## What shipped

### Added

- **Fixed physical-key layouts.** National/Jatiya, Probhat and Bijoy now map
  physical keys plus Shift/AltGr to Bangla characters. Assets
  `fixed-national-v1.json` and `fixed-probhat-v1.json` carry 203 key slots each,
  with provenance from public standards verified statically against the
  owner's reference installs. Bijoy reuses the National key map with the
  existing Bijoy output encoding.
- **Alternate phonetic tables.** Khipro and Phonetic/Banglish compile their
  stored rule tables through the existing regex transliterator and produce
  their own output. The selector shows one default **Avro (Phonetic)** style;
  `khipro` and `phonetic` remain accepted saved values.
- **Conjunct sequences.** A key that begins a sequence is held at most 30 ms.
  A matching next key replaces it with the conjunct; otherwise the single
  character is flushed. Focus changes, pause and mode changes clear the buffer.
- **Safer fixed typing.** The hook swallows letter keydowns in fixed mode, so
  an Bengali IME cannot compose the raw letter before Okkhor replaces it. If
  injection fails, the original ASCII letter is re-emitted.
- ADR 0021 and a written design/plan record the architecture.

### Fixed

- The first letter no longer stays behind in a browser address bar: focus
  tracking compares the owning process as well as the window handle.
- The English completion card no longer blanks on each keystroke while a caret
  sample is pending. Password samples and field changes still hide it.
- The card is placed just below and slightly left of the caret.

## Known limits

- The build is unsigned unless the owner supplies a trusted Authenticode
  certificate. SmartScreen/Defender will still warn; see `docs/release.md`.
- Real-key Windows QA in `docs/qa/0.9-checklist.md` is the owner's pass. The
  hook ignores injected keys, so automated tests cannot replace it.
- Fixed layouts show no word list. Next-word suggestions and local learning
  remain 0.9.x work.
- Legacy pickle/WTR1/STRI formats are still not loaded; the parity matrix
  names each gap.
