# Okkhor 0.9.1

Date: 2026-11-24
Channel: beta (portable, unsigned unless the owner signs the build)
Artifact: `Okkhor-0.9.1-win64-portable.zip`
SHA256: `88CA8A2EC7AC4B3C7E66D3EADC37993BA24DE6D746B01E95714860FB26883FBB`
The same hash is in `SHA256SUMS.txt` and the GitHub release notes.

0.9.1 is a bugfix patch on the 0.9.0 layout release. It fixes issues found in
the first real-key daily-use pass in Notepad.

## What shipped

### Fixed

- **English completion navigation.** Up/Down arrows move the completion
  highlight and Tab accepts the highlighted row. The hook takes those arrows
  only while the English list is visible; the caret no longer moves at the
  same time.
- **English Backspace and Tab.** Backspace keeps the completion rows alive,
  and Tab refuses to erase a token typed in another field.
- **Bangla Tab.** Tab accepts the highlighted Bangla candidate instead of
  cancelling the composition, which is why the selected word was never typed.
- **Partial commit recovery.** A `SendInput` batch that delivers the
  backspaces but not the replacement is retried once for the unsent tail, so a
  word is no longer left as blank space.
- **Tray icon.** The tray now finds `okkhor.ico` in the portable folder above
  `bin\` instead of falling back to the Windows default icon.
- **Duplicate Settings window.** Tray Settings signals the running UI through a
  session-local event; a second UI process also signals and exits instead of
  opening another window.
