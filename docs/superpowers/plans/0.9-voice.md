# 0.9 — Voice typing (last feature phase)

Voice typing is deliberately last: keyboard input, language data, the model,
UI, and release mechanics come first. This milestone ships **dictation as an
optional background feature** and must not regress the keyboard path.

Prerequisites: 0.5 UI, 0.6 model/AI, and the 1.0 packaging work are merged, or
the lead explicitly reorders. Binding rules: ADR 0002 (AI off the hot path),
`docs/security-privacy.md`.

## Global constraints

- Dictation is opt-in. No audio is captured until the user presses the control
  and grants microphone permission.
- Audio and transcripts are transient: never logged, never persisted by
  default, never sent anywhere without an explicit action.
- Voice never gates typing. The worker can be disabled, killed, or offline and
  the keyboard keeps working.
- No always-listening wake word in 0.9.
- No automatic injection into the focused window. A transcript lands in the
  dictation panel; insertion is a separate, explicit click (same 512-unit cap
  as the on-screen keyboard).
- Provider keys are environment-only and never committed. Tests use mocks and a
  local fake server; real Google/other providers remain owner-gated.
- Model/VAD work stays CPU-only and bounded; no transformer on the hot path.

## Task 1 — `okkhor-speech` capture core

Deliver:

1. `crates/okkhor-speech` (`#![forbid(unsafe_code)]`):
   - `AudioSource` trait, `AudioChunk` (PCM16 mono 16 kHz), bounded ring buffer
     (max 30 s), `WavFileSource` (PCM16 only, header validated, size capped),
     and `MicSource` behind feature `mic` using `cpal` (default input device,
     linear resampler to 16 kHz).
   - Device enumeration API for the UI; no device names in logs (log a count
     and a stable index).
   - Energy-gate segmenter with max segment 10 s; no ML VAD.
   - Typed errors: `NoDevice`, `PermissionDenied`, `UnsupportedFormat`,
     `TooLong`, `Cancelled`.
2. Tests: WAV accept/reject/corrupt header, ring-buffer overflow, segmenter
   boundaries, resampler identity/quality bounds, cancel, no-device path.

Acceptance:

- `cargo test -p okkhor-speech` green; root checks green.
- No microphone access in CI; the `mic` feature is exercised only by an
  ignored manual test.

---

## Task 2 — Transcription providers and worker integration

Deliver:

1. `SpeechProvider` trait, `MockProvider`, `DisabledProvider`, and optional
   `GoogleSpeechProvider` behind `http` (env `OKKHOR_GOOGLE_SPEECH_KEY`),
   fake-server tested. 30 s hard cap, cancellation, single-flight.
2. Worker: `speech.transcribe` job with start/stop/cancel, bounded queue,
   health, and a transcript response that is never cached to disk in 0.9.
3. Daemon broker: opt-in check, one active dictation session, proxy to worker,
   typed errors, no audio or transcript in logs.
4. UI: Settings → Speech (opt-in, provider, device list, key presence), and a
   Dictation panel: record button, elapsed time, level meter from RMS only,
   Stop/Cancel, transcript text area with Copy and explicit Insert. No
   auto-insert, no selection capture.
5. Docs: `docs/speech.md` (privacy, permissions, providers, failure modes,
   gaps), `docs/security-privacy.md` update.

Acceptance:

- Worker kill / provider outage leaves the keyboard and ranking untouched.
- Tests: provider mapping, timeout, cancel, cap, fake-server success/error,
  policy rejection, no-text-in-logs inspection.
- System-loopback capture is explicitly out of scope and documented as a gap.

## Task 3 — Optional local fallback and packaging

Deliver:

1. Decide, with measurements, whether a small CPU model is justified for
   offline dictation. If not, ship "cloud-only, opt-in" and document the gap.
   No new runtime without an ADR.
2. Package the mic feature and worker sidecar in the installer; default build
   includes the worker but speech stays disabled until opt-in.
3. Size/latency record: worker startup, capture-to-transcript p50/p95, memory,
   installer delta.

Acceptance:

- Installer builds with the speech sidecar and speech disabled by default.
- No regression in typing/ranking budgets.
