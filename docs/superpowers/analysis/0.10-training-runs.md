## 1B pipeline (2026-11-25)

Both 1B corpora are fetched (`corpus/bangla-1b` 18.0 GB,
`corpus/english-1b` 6.2 GB). Training runs from memory-mapped uint32 shards, so
RAM stays flat.

**Shard build** (`scripts/build-nextword-shards.py`):

- Two passes: a word count over the train split, then a token write.
- Held-out split is 2 % chosen by a stable BLAKE2b hash of the line, so train
  and eval never overlap and the split is reproducible.
- Vocabulary capped at **200,000** (min count 10) to bound the output layer.
- Layout: `train.bin`, `eval.bin`, `vocab.json`, `meta.json` with SHA-256.
- Sentence boundaries are `<eos>` (id 2); `<pad>` 0, `<unk>` 1.
- Smoke on a 200k-line slice: 2.4M train tokens, vocab 40k, 2.7 s.

**Trainer** (`scripts/train-nextword-stream.py`):

- Random windows gathered from `np.memmap`; `<eos>` inside a window is masked
  to `<pad>`, so a window never crosses sentences.
- Throughput settings: **bf16 autocast** (no loss scaler), **fused AdamW**,
  **pinned-buffer prefetch**, and **`torch.compile`** with an eager fallback.
  Compile needs Python headers, which are installed without root:
  `apt-get download libpython3.12-dev`, `dpkg -x` into the project, then
  `CPATH=<prefix>/usr/include:<prefix>/usr/include/python3.12:<prefix>/usr/include/x86_64-linux-gnu`.
- **Batch 3072** on the full 200k vocabulary. The probe optionally halves the
  batch until a full step fits, including optimizer state.
- Same 768-d / 6-layer / 12-head / FF 3072 teacher, context 8, 1 epoch,
  AdamW 4e-4.
- Checkpoint every 5,000 steps; `--resume` continues, `SIGTERM`/`SIGINT` saves
  and exits 75, and a `<prefix>.pause` file pauses after a checkpoint until it
  is removed. The queue treats exit 75 as "paused", not as a failure.
- Logs `vram`/`reserved`/`tok/s` every 250 steps.
- Writes `*.metrics.json` with top-1/top-5 and wall time.
- Smoke on the CPU slice: pause, resume and metrics verified.

### Measured throughput ladder (this MIG slice)

The slice has 16 SMs. Raw GEMM at the output-layer shape: fp32 5.43, bf16
10.82, fp16 12.20 TFLOPS.

| Config | tok/s | Peak VRAM |
| --- | ---: | ---: |
| 2048, eager | 5,447 | 9.2 GB |
| 3072, eager | 5,555 | 12.2 GB |
| 3072, compile | 8,793 | 12.2 GB |
| 3072, compile, fp16 | 8,676 | 12.2 GB |
| 3584, compile, fp16 | 8,850 | 13.7 GB |
| **3072, compile, bf16 (chosen)** | **8,793** | 12.2 GB |
| 128k vocab, 4096, compile | 10,596 | 11.4 GB |

Batch 3584 OOM'd in the real run even though the probe passed: Adam allocates
its state on the first update, so the probe was ~2 GB optimistic. The probe now
runs a full optimizer step; 3072 is the largest batch that survives training.

The 128k run was rejected by the owner: **quality first, the full 200k
vocabulary stays**. At 200k the step costs ~1.18 GFLOP/token, so 12k tok/s
would need 14.2 TFLOPS — above the slice ceiling. One epoch at 3584 is
~32 h per language.

**Queue** (`overnight-1b.sh`): waits for both shard sets and a free GPU, then
runs Bangla and English back-to-back with up to three attempts each and
`state/*.done` markers.

Rough projections on the 1g slice: shard build ~10–20 min per language; one
epoch at 1B tokens ~1.5–2 days per language.


## Commands

```bash
# on uiu-h200
cd ~/okkhor-training/okkhor
. .venv/bin/activate

# full corpus conversion (writes ../corpus/phase5-licensed/*full*)
python ../build_full_dataset.py

# full collection

  --input ../corpus/phase5-licensed \
  --out ../datasets/phase5-licensed-full \
  --max-rows 5000000 --max-file-mb 2000 --force

# bigram
python ../train_nextword.py

# context-2 MLP
python ../train_nextword_mlp.py

# context-8 transformer
tmux new-session -d -s nextword \
  'cd ~/okkhor-training/okkhor && . .venv/bin/activate && \
   python ../train_nextword_transformer.py > ../artifacts/nextword-train.log 2>&1'
```

## Gates before shipping any model

- Frozen licensed holdout top-1 must beat the baseline by ≥1.0 point.
- Top-5 must not regress.
- Inference p99 ≤3 ms (Tier 2) after quantisation.
- No user text in the model, the manifest, or the logs.
- Package is checksummed, signed, and rollback-tested.
