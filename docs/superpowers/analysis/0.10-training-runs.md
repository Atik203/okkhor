# 0.10 training runs (uiu-h200)

Status: first real runs completed; the context-8 transformer was started on the
full collection. No user data, no download inside the training scripts, and no
model is enabled in the app until the A/B gate passes.

## Environment

- Host: `uiu-h200`, NVIDIA H200-1-18C MIG `1g.18gb`, 18,432 MiB VRAM,
  driver 580.178.04, CUDA 13.5.
- Python 3.12.3 project venv; PyTorch `2.11.0+cu128` with CUDA available.
- Workspace: `~/okkhor-training` (repo clone + corpus + datasets + artifacts).
- Long runs use `tmux`; the server is allowed to run continuously.

## Dataset (first full collection)

| Source | Full rows | Notes |
| --- | ---: | --- |
| Bengali Wikipedia 20231101.bn | 143,069 articles → **2,249,223 sentences** | 571 MB extracted text |
| BanglaTLit train | 42,864 valid pairs | streaming yields 42,864 non-empty pairs |
| BanglaSEC train | 957,746 corrections | full train split |
| Prepared train rows | **~3.14M** | deduped, NFC, split by case hash |
| Bangla tokens | **31,627,519** | 924,219 unique; 177,943 with count ≥ 5 |
| Frequency tokens | 374,912 distinct in the capped run; full run larger | `freq/bn-tokens.tsv` |

The pipeline run on the full collection took **2m35s**, peak RSS about 5.1 GB.

## Runs

### 1. Next-word bigram (CPU baseline)

- Train: 435,533 sentences, 6,345,123 tokens (capped run).
- Held-out: 22,922 sentences, 310,162 pairs.
- Metrics: **top-1 0.1229, top-5 0.2507**, coverage 0.9328.
- Time: 12 s CPU.
- Artifact: `artifacts/nextword-bigram-v1.json` (8.9 MB).

### 2. Next-word MLP, context 2 (GPU baseline)

- Vocabulary 63,161; train pairs 5,909,590; eval pairs 310,162.
- Model: 2 embeddings (64), hidden 256, output vocab.
- Metrics: **top-1 0.1485, top-5 0.2794**.
- Time: **5m41s** wall clock for 2 epochs.
- Artifact: `artifacts/nextword-mlp-v1.pt` (83 MB).

### 3. Next-word Transformer, context 8 (running)

- Full collection: 2,093,629 sentences; vocabulary 177,943.
- Model: embedding 256, d_model 512, 4 layers, 8 heads, FF 1024,
  batch 4096, 3 epochs, AMP fp16.
- Training uses the full token set (~31.6M pairs).
- Expected: several hours on the 1g slice. Metrics will be written to
  `artifacts/nextword-transformer-v1.metrics.json` and logged to
  `artifacts/nextword-train.log`.

## Commands

```bash
# on uiu-h200
cd ~/okkhor-training/okkhor
. .venv/bin/activate

# full corpus conversion (writes ../corpus/phase5-licensed/*full*)
python ../build_full_dataset.py

# full collection
python scripts/prepare-datasets.py \
  --input ../corpus/phase5-licensed \
  --out ../datasets/phase5-licensed-full \
  --max-rows 5000000 --max-file-mb 2000 --force

# bigram
python ../train_nextword.py

# context-2 MLP
python ../train_nextword_mlp.py

# context-8 transformer
tmux new-session -d -s nextword \
  'cd ~/okkhor-training/okkhor && . .venv/bin/activate && \
   python ../train_nextword_transformer.py > ../artifacts/nextword-train.log 2>&1'
```

## Gates before shipping any model

- Frozen licensed holdout top-1 must beat the baseline by ≥1.0 point.
- Top-5 must not regress.
- Inference p99 ≤3 ms (Tier 2) after quantisation.
- No user text in the model, the manifest, or the logs.
- Package is checksummed, signed, and rollback-tested.
